# 2026-04-13

## 課題: 通し練習 Run-1（Week1〜4全設定）

### ミス1: Dialer0 の必須コマンド漏れ
- **何が起きたか**: PPPoEセッションが SHUTDOWN 状態のまま、Dialer0 に IP が割り当てられなかった
- **原因**: `ip address negotiated` と `dialer pool 1` を入れ忘れた
- **対策**: Dialer0 設定時は必ずこの2行をセットで入れる

### ミス2: ACL を LANポートに誤適用
- **何が起きたか**: R-WS が DHCP でアドレスを取得できなかった
- **原因**: PROTECT_LAN を Fa0/0（LAN側）inbound に適用してしまった。DHCP DISCOVER が `deny ip any any` で落とされた
- **対策**: ACL適用先は要件をよく読む。WANフィルタはWANポートに適用

### ミス3: PPPoE環境での ACL 適用先
- **何が起きたか**: Fa0/1 に `ip access-group` を適用したが、R-WAN からの ping がブロックされなかった
- **原因**: PPPoEクライアントでは IP トラフィックが物理インタフェースを素通りし、Dialer0 で処理される。物理インタフェースの `ip access-group` は PPPoE パケットには効かない
- **対策**: PPPoEクライアント環境では ACL を **Dialer0 inbound** に適用する

## 課題: 通し練習 Run-2（Week1〜4全設定 60分以内目標）

### ミス1: デフォルトルート漏れ
- **何が起きたか**: R-BR から 8.8.8.8 への ping が失敗した
- **原因**: `ip route 0.0.0.0 0.0.0.0 Dialer0` を入れ忘れた
- **対策**: PPPoE設定後はデフォルトルートをセットで入れる
