# 2026-06-10

## ACL のネットワーク行末に `;` が必要

**状況**: named-checkconf がエラーを返した

**誤り**:
```
acl "osaka-office" {
    172.16.100.0/24
};
```

**正解**:
```
acl "osaka-office" {
    172.16.100.0/24;
};
```

BIND の設定はほぼ全行に `;` が必要。

---

## `forward only` を forwarders とセットで書く

**誤り**: `forwarders { 172.16.100.11; };` だけ書いて `forward only;` を省略

**正解**:
```
forwarders { 172.16.100.11; };
forward only;
```

`forward only` がないと「フォワーダが応答しなかった場合に自分で外部を問い合わせる」動作になる。

---

## match-clients に /24 が必要

**誤り**: `match-clients { 172.16.100.0; };`

**正解**: `match-clients { 172.16.100.0/24; };`

サブネットマスクなしだとそのホストIPのみにマッチし、ネットワーク全体には効かない。
