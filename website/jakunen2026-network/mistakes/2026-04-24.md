# 2026-04-24

## R-06 総復習課題

### ミス1: Fa0/1 に IPv4 アドレス未設定
- **状況**: R-HQ Fa0/1 に `ip address 10.1.12.1 255.255.255.248` を設定し忘れた
- **影響**: R-BR → R-HQ Fa0/1 への ARP が解決できず、R-BR 経由の全通信が不可
- **対策**: Fa0/1 の設定ブロックに入ったら IP アドレスを必ず最初に入れる

### ミス2: PROTECT_WAN を IPv6 ACL として作成
- **状況**: `ipv6 access-list PROTECT_WAN` で作成し `ipv6 traffic-filter PROTECT_WAN in` で適用
- **影響**: IPv4 の ping がブロックされない（IPv6 トラフィックのみフィルタ）
- **正解**: `ip access-list extended PROTECT_WAN` + Dialer0 で `ip access-group PROTECT_WAN in`
- **対策**: WAN 保護 ACL は必ず `ip access-list extended`。IPv6 ACL は `ipv6 access-list` と覚える

### ミス3: R-BR Fa0/0 のサブネットマスクが /30
- **状況**: 255.255.255.252 (/30) を入力。正しくは 255.255.255.248 (/29)
- **影響**: 静的 NAT の global アドレス (10.1.12.5) が Fa0/0 のサブネット外になり proxy ARP が働かず
- **対策**: /29 = 255.255.255.248、/30 = 255.255.255.252 の違いをしっかり確認する
