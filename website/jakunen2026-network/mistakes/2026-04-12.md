# 2026-04-12

## PPPoE + 動的PAT + DHCP

### dialer pool vs dialer-group
- `dialer pool 1` と書くべきところを `dialer-group 1` にしてしまう
- Dialer インタフェース側は `dialer pool`、物理 IF 側は `pppoe-client dial-pool-number`

### pppoe-client 忘れ
- Fa0/0 に `pppoe-client dial-pool-number 1` を入れないと Dialer0 に IP が来ない

### no shutdown 忘れ（Fa0/1）
- Fa0/1 はデフォルト shutdown。`no shutdown` を忘れると DHCP 払い出しが起きない

### NAT outside をFa0/0に設定してしまう
- PPPoE では outside は `Dialer0`。物理インタフェース Fa0/0 ではない

### DHCP default-router の混同
- `default-router` = クライアントのデフォルトGW = **R-CE の LAN 側 IP（例: 10.0.1.1）**
- DNS サーバ（インターネット側 IP）を間違えて入れてしまうミスに注意

### GNS3環境の制約
- PPPoE + NAT の組み合わせでは `no ip cef` が必要（CEF がNATの戻りパケットをバイパスする）

## IPv6 ACL

### ACLの順序ミス
- `deny` を `permit ipv6 any any` より後ろに書くと deny が永遠にマッチしない
- 必ず deny → permit NDa → permit NDs → permit any の順で書く

### ACLの適用インタフェース間違い
- ブロックしたいパケットが入ってくるインタフェースに in で付ける
- R3→R1をブロックしたい → R3側のFa0/1 in（Fa0/0ではない）

### deny の宛先を広く取りすぎる
- `deny ipv6 src_net dst_net/64` とすると同じ /64 内の他のアドレスも巻き込む
- 特定ホストだけブロックしたい場合は `host` を使う: `deny ipv6 src_net host dst_addr`
