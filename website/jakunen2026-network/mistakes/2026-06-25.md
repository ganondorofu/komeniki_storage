# 2026-06-25

## apache2 設定ミス

- `</VirtualHost>` の `/` を忘れた → `<VirtualHost>` になってシンタックスエラー
- `SSLCertificateKey` と書いた → 正しくは `SSLCertificateKeyFile`
- `a2enmod ssl` を忘れた → `SSLEngine` が invalid command になる
- `a2ensite` 後に `systemctl reload apache2` を忘れた → 設定が反映されない
- ServerName のタイポ: `in-www.osaka-skills.jp` → 正しくは `in.osaka-skills.jp`

## 作業対象VM の間違い
- osv2 (ns2) のターミナルで apache2 の設定をしようとした
- apache2 は osv1 (ns1) にある。ホスト名を確認してから作業すること
