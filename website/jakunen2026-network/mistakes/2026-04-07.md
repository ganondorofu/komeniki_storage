# 2026-04-07

## PAT設定

### overload の付け忘れ
- `ip nat inside source list 1 interface Fa0/0` だけだと動的NAT（1対1）になる
- PAT（多対1）にするには末尾に `overload` が必要

### ip nat inside をインタフェースに付け忘れ
- NATルールを作っただけでは動作しない
- 全ての内部インタフェース（Fa0/1, Lo0, Lo1 など）に `ip nat inside` が必要

### ACL の対象範囲の漏れ
- 変換したいアドレスが ACL の permit 範囲に入っていないと NAT されない
- Lo1（172.16.1.1）を変換したいなら `access-list 1 permit 172.16.1.0 0.0.0.255` が必要

## 静的NAT設定

### inside/outside をインタフェースに付け忘れ
- `ip nat inside source static` コマンドだけでは動作しない
- Fa0/0（outside）、内部インタフェース（inside）の設定が必須

### NATアドレスが相手サブネット外の場合は相手にルートが必要
- 変換後アドレス（global）がリンク間サブネット外なら対向ルータにスタティックルートを追加する

## 設計注意

### Loopback に内部 LAN と同じサブネットを使うと overlaps エラー
- Fa0/1 が 172.16.0.0/24 を持つ場合、Lo0 に 172.16.0.x/32 は設定不可
- Loopback は別サブネット（例: 10.10.10.1/32、192.168.100.1/32）を使うこと
