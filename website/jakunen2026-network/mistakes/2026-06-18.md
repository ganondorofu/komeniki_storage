# 2026-06-18

## MX レコードの優先度を書き忘れた

**状況**: ゾーンファイルの読み込みに失敗し external view が応答しなくなった

**誤り**:
```
@  IN  MX  mail.osaka-skills.jp.
```

**正解**:
```
@  IN  MX  10  mail.osaka-skills.jp.
```

優先度（ここでは `10`）が抜けるとゾーンファイルの構文エラーになる。`named-checkzone` を必ず実行して確認する。

---

## タイポ: `maiil`（i が1つ多い）

**状況**: `maiil.osaka-skills.jp.` とタイポ → ゾーン読み込み失敗

MX・NS などホスト名を手打ちするときは `named-checkzone` で必ず確認する。

---

## ゾーンファイル変更後に bind9 を再起動しなかった

**状況**: osv2 のゾーンファイルを変更したが bind9 を再起動せず、スレーブ（osv1）に NOTIFY が送られず古いデータが残った

**対策**: ゾーンファイルを変更したら必ず `systemctl restart bind9`（または `rndc reload`）を実行する。スレーブへの反映はマスタの再起動（NOTIFY発行）が起点になる。
