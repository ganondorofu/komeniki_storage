# 2026-06-17

## 外部ゾーンに内部IP を設定してしまった

**状況**: osv1 の external view（外部向けマスタゾーン）のAレコードに内部IPを書いた

**誤り**:
```
mail  IN  A  172.16.100.11   ← 内部IP
osv1  IN  A  172.16.100.11   ← 内部IP
www   IN  A  172.16.100.12   ← 内部IP
```

**正解**:
```
mail  IN  A  192.168.0.11    ← 外部IP
osv1  IN  A  192.168.0.11    ← 外部IP
www   IN  A  192.168.0.12    ← 外部IP
```

**原則**: split-horizon で2つのゾーンがある場合
- internal view（内部向け）→ 172.16.100.x（実際のVM IP）
- external view（外部向け）→ 192.168.0.x（外部から見えるIP）

## allow-transfer を zone ブロックに入れ忘れた

**誤り**: zone ブロックに `type master` だけ書いた

**正解**:
```
zone "osaka-skills.jp" {
    type master;
    file "/etc/bind/db.osaka-skills.jp";
    allow-transfer { 172.16.100.11; };   ← 必要
};
```

allow-transfer がないとスレーブへのゾーン転送が拒否される。
